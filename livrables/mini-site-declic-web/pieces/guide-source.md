# Déclic Web — Guide source fictif

LN-IA · Module 05 · S18 · Création pédagogique, 23 novembre 2026

Ce cas, ses valeurs et ses documents sont inventés pour l’exercice. Réutilisation autorisée dans cet atelier avec cette mention.

## Contexte

Le support propose une page locale : HTML organise le contenu, CSS règle la présentation et JavaScript affiche une explication. Aucun compte ni serveur n’est requis.

## Contenu utilisable

Le navigateur lit les fichiers et affiche la page. Commencer par ouvrir index.html, repérer les trois fichiers, puis faire une modification à la fois. Comparer avant et après. Le support ne traite ni serveur, ni API, ni mise en ligne automatique.

### HTML

Repérer titre, paragraphes, image et lien dans index.html.

### CSS

Changer une couleur dans css/styles.css et observer la présentation.

### JavaScript

Déclencher un bouton qui affiche puis masque une explication.

## Affiche associée

Voir affiche.svg : synthèse visuelle dédiée à ce projet ; elle ne justifie aucune information supplémentaire.

## Limites

Ce parcours est une initiation ; il ne promet pas la maîtrise complète du développement web.

## Production attendue

index.html avec six sections ; une fiche locale de destination. Action principale : Explorer les trois fichiers. Créer la destination à partir de la fiche fournie. Joindre ces fichiers à l’agent ; le texte d’un chemin ne transmet pas son contenu.
