LE POINT DE DÉPART

Observer les rôles de trois fichiers dans une page locale.

Ouvrez index.html dans votre navigateur. Repérez les trois fichiers, puis faites une modification à la fois. Comparez avant et après.

D’après le guide source · SRC-01

COMPRENDRE LES RÔLES

Qui fait quoi dans la page ?

HTML, CSS, JavaScript et le navigateur coopèrent. Voici les repères pour les distinguer.

index.html

HTML organise.

Repérez le titre, les paragraphes, l’image et les liens : c’est la structure du contenu.

css/styles.css

CSS présente.

Changez une couleur dans ce fichier et observez la présentation.

js/app.js

JavaScript réagit.

Déclenchez le bouton qui affiche puis masque une explication.

Et le navigateur ? Il lit les fichiers et affiche la page. Aucun compte ni serveur n’est requis pour ce support.
